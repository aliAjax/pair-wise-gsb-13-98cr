# 加油站班次油罐交接

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript、Element Plus
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

## 业务闭环

按班次（早/中/晚班）和油品（92#、95#、0#柴油）记录：

- **开班罐存**：新开一班时自动继承最近一个已交班班次的交班实测罐存
- **进油量 / 销量**：本班录入
- **账面罐存 = 开班罐存 + 进油量 − 销量**（系统自动计算）
- **交班实测罐存**：交班时人工录入，差额 = 实测 − 账面

### 交班校验（不通过不能交班）

1. 每个油品必须填写交班实测罐存
2. 账面罐存不能为负（销量不能超过开班罐存 + 进油量）
3. |绝对差额| > 50 升，或相对差额（差额/账面）> 0.5% 时，**必须填写损溢原因**

### 冻结与修订

- 交班成功后记录冻结，不能重复交班、不能直接改写
- 更正只能**新建带修订原因的新版本**，旧版本原样保留，可随时展开对比
- 当前生效数据始终取最新版本

### 跨班衔接

- 系统自动比对每个班的开班罐存与上一已交班班次的实测值
- 修订历史班次导致数据不一致时，顶部“跨班数据冲突”面板会列出：油品、本班开班量、上一班实测量和差额，可一键跳到对应班次处理
- 数据保存在浏览器 localStorage（key：`dfwlfront-7-tank-handoff-v1`），刷新/重开页面后跨班数据仍在

## 代码结构

- `src/types.ts`：班次、油品行、冻结版本、校验结果、冲突类型
- `src/store.ts`：本地持久化、阈值校验（`ABS_LIMIT=50`、`REL_LIMIT=0.005`）、开班继承、交班冻结、修订版本、跨班冲突
- `src/components/FuelTable.vue`：按油品录入/展示的计量表格，实时显示账面、差额与相对差额
- `src/components/ShiftCard.vue`：单个班次的草稿编辑、交班、版本历史与修订
- `src/App.vue`：开班、指标、冲突面板、交班阻塞清单与班次列表
