# 加油站油罐班次交接闭环

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

每班按油品（92#/95#/98#/0#）记录开班罐存、进油量、销量、交班实测罐存，数据通过 `localStorage` 落盘（key：`dfwlfront-7-tank-handover-v1`），刷新后跨班数据仍在。

## 业务规则

- **账面罐存** = 开班罐存 + 进油量 − 销量；差额 = 交班实测 − 账面（正溢余、负损耗）。
- **交班卡控**：绝对差额 > 50 L，或相对差额（差额 ÷ 账面）> 0.5% 时不能交班，必须逐油品填写损溢原因；同时所有油品必须填写实测值。
- **冲突清单**：卡控触发时列出每项冲突的油品、账面量、实测量、差额及阻断原因。
- **跨班继承**：下一班开班罐存自动继承上一班（现行有效版本）的交班实测值，只读不可改。
- **冻结与修订**：已交班记录冻结，不可编辑/删除；更正只能「新建修订」，必须填写修订原因，旧版本保留并标记为「已被修订替代」。
